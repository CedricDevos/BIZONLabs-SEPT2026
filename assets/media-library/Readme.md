Place approved public-facing BIZON Labs photos and videos in this folder:

assets/media-library

When the site is rebuilt, supported files in this folder are added to the media viewer automatically in:

dist/index.html

Keep private, confidential, or sensitive files out of this folder.

Supported public formats are JPG, JPEG, PNG, WEBP, GIF, MOV, MP4, and WEBM. Convert HEIC photos to JPG before publishing.
